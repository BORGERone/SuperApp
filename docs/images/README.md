# Картинки для README

| Файл | Что это |
|---|---|
| `banner.png` | Шапка корневого `README.md`: фон + заголовок «SuperApp», слоган и логотип |
| `logo.png` | Логотип: двойной шеврон, градиент `#667eea → #8b5cf6` (256×256, прозрачный фон) |
| `screen-mail.png`, `screen-drive.png`, `screen-tasks.png`, `screen-login.png` | Кадры интерфейса: «Почта», «Сетевой диск», «Задачи», экран входа |
| `qr-server.png` | QR-код на `https://prostroykrym.ru` (для быстрого открытия приложения с телефона) |
| `raw-*.jpg` | Исходники от генератора изображений — используются только для баннера, кадры интерфейса рисуются кодом |

> Кадры интерфейса — **иллюстрации**, а не скриншоты: вместо текста и данных на
> них мягкие «скелетон»-формы и пастельные градиенты. Читаются только ключевые
> подписи — те, по которым модуль узнаётся. Состав экранов при этом взят из
> реального клиента (`packages/client/src`).

## Как сделаны кадры интерфейса

`make-screens.py` рисует четыре кадра с нуля на Pillow, без браузера и скриншотов:

```bash
pip install Pillow          # нужен ещё шрифт DejaVu: пакет fonts-dejavu-core
python3 docs/images/make-screens.py     # запускать из корня репозитория
```

Стиль намеренно «макетный», а не «как настоящий скриншот»:

- **скелетон вместо текста** — строки писем, заголовки карточек, содержимое
  письма и имена файлов нарисованы скруглёнными плашками; данных на картинке нет;
- **пастельные градиенты** — аватары, папки, страницы файлов, плашки-чипы и
  полоски прогресса: у каждого элемента свой мягкий градиент (индиго, бирюза,
  амбра, роза, коралл, синий, фиолет);
- **свёрнутая боковая панель** — на кадрах «Диск» и «Задачи» меню показано
  сжатым в рейку иконок (как в приложении по кнопке сворачивания); имя
  пользователя в шапке не подписано — только кнопка «Выйти»;
- **подписи** — только короткие и узнаваемые: «Почта», «Диск», «Задачи»,
  «Настройки» и пункты почты в сайдбаре, «Поиск писем...», «Сетевой диск»,
  «Загрузить файл», «Создать папку», «Обновить», «Назад», «Выбрано: 1»,
  «Скачать», «Удалить», «Поиск карточек», «Все ответственные», «Архив»,
  «Колонок: 3», «Карточек: 7», «В работе» / «На проверке» / «Выполнено»,
  «Добавить карточку», «Новая колонка», «Создать колонку», «Логин», «Пароль»,
  «Запомнить пароль», «PIN-код», «Войти»;
- **иконки** — контурные, по мотивам lucide-набора из клиента (`HardDrive`,
  `FolderOpen`, `Edit`, `Inbox`, `Send`, `Trash2`, `Filter`, `Star`, `Archive`,
  `RefreshCw`, `Upload`, `Plus` и т. д.);
- **цвета** — `#667eea` → `#764ba2` для заголовков, `#6366f1` → `#a855f7` для
  кнопок (см. `tailwind.config.js` и `style.css`);
- **оформление** — рамка со скруглением, мягкая тень и светлый фон; кадр
  рисуется в двойном размере и уменьшается, поэтому линии гладкие, а тени мягкие.

Логический размер кадра — 1440×900 (плюс поля), сайдбар — 300 px. Что нарисовано
в каждом кадре и в каком порядке — в функциях `draw_mail`, `draw_drive`,
`draw_tasks`, `draw_login`: списки писем, плиток и колонок правятся прямо там.

## Заменить макеты настоящими скриншотами

1. Сделайте скриншот окна приложения (удобно на Windows: `Win + Shift + S`).
2. Обрежьте до рабочей области окна и сохраните рядом с именем `raw-*.jpg`,
   например `docs/images/raw-mail.jpg`.
3. Прогоните `python3 docs/images/make-images.py --shots` — скриншот получит
   такое же скругление, тень и фон, как у баннера, и перезапишет
   `screen-mail.png`.
4. Закоммитьте файл — README подхватит его автоматически, править текст не нужно.

## Баннер и логотип

```bash
python3 docs/images/make-images.py      # logo.png + banner.png
```

`make-images.py` собирает логотип и баннер из `raw-banner.jpg`; текст баннера
(«Почта · Диск · Задачи», «Всё в одном приложении, развёрнутом на вашем сервере»)
редактируется прямо в скрипте. Без ключа `--shots` он не трогает `screen-*.png` —
их рисует `make-screens.py`.

## QR-код

`qr-server.png` сделан пакетом [`qrcode`](https://www.npmjs.com/package/qrcode) для ссылки
`https://prostroykrym.ru`. Если домен изменится:

```bash
npm i qrcode
node -e "require('qrcode').toFile('docs/images/qr-server.png', 'https://новый-домен.ру', \
  {color:{dark:'#3730a3', light:'#ffffff'}, margin:2, width:512}, e => { if (e) throw e; })"
python3 - <<'EOF'
from PIL import Image
qr = Image.open('docs/images/qr-server.png').convert('RGB')
bg = Image.new('RGB', (qr.width + 64, qr.height + 64), (255, 255, 255))
bg.paste(qr, (32, 32)); bg.save('docs/images/qr-server.png', optimize=True)
EOF
```
